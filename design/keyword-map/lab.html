What we can change on the keyword map

Same 20 keywords from the three-source river sample, same groups as the network. Start with a preset, then change one control at a time to see what each visual variable adds. Hover a word for its numbers and partners.

Presets

Theme names are written by hand for this sample, standing in for names Claude would suggest. A group with no clear theme stays unnamed.

The visual variables

Each one can carry a different piece of information. The rule of thumb: position, and the background regions drawn from it, show the groups. Size shows how common a word is. Color names the group. Avoid making two of them say the same thing, or the map gets louder without saying more.
